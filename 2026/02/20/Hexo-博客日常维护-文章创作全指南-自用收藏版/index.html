优先检查三件事：

  • hexo d 是否真正执行成功
  • GitHub Pages 发布分支是否正确
  • 浏览器是否缓存了旧的 JS/CSS

部署时报 .deploy_git 权限错误

可以先关闭编辑器和终端里可能占用的进程，再重试。仍然失败时，手动删除 .deploy_git 后重新部署。

维护习惯

每次发布前做一个小检查：

  • 标题是否清楚
  • 分类是否只有一个
  • 标签是否准确
  • 本地是否预览过
  • 命令和链接是否可读

博客维护不需要复杂。稳定写、定期整理、少折腾主题，就是最省心的方案。
